# experiments/ — your own investigations

This folder is for **your** extensions. Copy a notebook, change one thing, and record what happened. Use the same 12-part structure as the lab notebooks:

A. title · B. research question · C. mathematical foundation · D. theoretical prediction · E. design · F. implementation · G. results · H. theory-vs-empirical comparison · I. interpretation · J. limitations · K. conclusion · L. further investigation.

Rules of the lab: write the prediction **before** you run the code; fix a seed (`plab.make_rng(seed)`); report standard errors; remember a simulation is evidence, not proof.

Suggested first extensions are listed under "L. Further investigation" at the end of every experiment.
